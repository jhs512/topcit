# 목원대학교 TOPCIT 대비 특강

2026년 제26회 TOPCIT 정기평가를 준비하는 목원대학교 재학생을 위한 수업 안내입니다. 3회 특강에서 **IT비즈니스·윤리, 프로젝트 관리와 의사소통, 시스템아키텍처, 정보보안**을 배웁니다. 아래에서 시험 구성과 준비 방법, 수업 일정을 확인하세요.

[공식 2026년 시행계획 공고](https://www.topcit.or.kr/board/notice/detail.do?seq=841)

**[문제은행 열기 — TOPCIT 한 문제씩](https://jhs512.github.io/topcit/)**

담당 교재 4개 학습영역별 100문항, 총 400개의 자체 객관식 연습문제를 풀어 보세요. 공식 기출문제를 복제한 자료가 아닙니다.

- **문제풀이:** 한 문제씩 제출하고 정답·해설을 확인합니다. 같은 문제를 서로 다른 출제에서 두 번 연속 맞히면 완료되며, 틀리면 해당 문제의 연속 정답이 0회가 됩니다. 완료한 문제는 다시 출제하지 않습니다.
- **전체보기:** 선택한 영역의 문제와 보기를 원래 순서대로 한 페이지에서 읽습니다.
- **개념모드:** 모든 문제의 정답과 추가 설명을 펼쳐 읽습니다. 두 읽기 모드는 학습 진도를 올리지 않습니다.

학습기록은 현재 기기·브라우저에 저장됩니다. **다른 기기에서 이어가기**로 링크를 복사해 본인에게 보내면 링크 생성 시점의 진도를 가져올 수 있습니다. 자동 동기화는 아니므로 최신 진도를 옮길 때는 링크를 다시 만드세요. 기존 진도가 있는 기기에서는 비교한 뒤 교체할 수 있습니다.


## 1. 오리엔테이션: TOPCIT 시험 이해하기

먼저 TOPCIT이 무엇을 평가하는지, 점수를 어떻게 해석하는지 알아봅니다. 평가 영역과 문항 유형을 살펴보고 응시 절차와 준비물을 확인하세요.

### 어떤 시험인가요?

TOPCIT(Test Of Practical Competency in IT)은 IT·소프트웨어 분야에서 실제 업무 문제를 해결하는 데 필요한 역량을 평가합니다. 기술 지식뿐 아니라 비즈니스 이해, 프로젝트 관리, 의사소통 등을 함께 다룹니다. 배운 개념을 업무 상황에 적용할 수 있는지가 핵심입니다. [공식 TOPCIT 소개](https://topcit.or.kr/introduction/topcit.do)

### 합격·불합격인가요, 점수제인가요?

결과는 **1,000점 만점의 점수와 5단계 역량 수준**으로 이해하면 됩니다. 수준 3은 400점부터지만, 이를 모든 기관에 공통인 합격선으로 해석하지 않습니다. 학교의 성적 활용 기준은 학교 안내를 확인하세요. [공식 역량 수준 안내](https://www.topcit.or.kr/introduction/ability.do)

TOPCIT 공식 안내에 따르면, TOPCIT을 활용하는 협약 기업·기관 다수가 **수준 3(400점) 이상 응시자를 우대**합니다. 실제 인정·우대 여부와 조건은 기업별 채용공고에 따라 다릅니다. [공식 역량 수준 및 기업 활용 안내](https://www.topcit.or.kr/introduction/ability.do)

| 역량 수준 | 점수 구간 |
| --- | ---: |
| 수준 1 | 0~149점 |
| 수준 2 | 150~399점 |
| 수준 3 | 400~649점 |
| 수준 4 | 650~849점 |
| 수준 5 | 850~1,000점 |

점수 구간 출처: [공식 TOPCIT 소개의 역량 수준](https://topcit.or.kr/introduction/topcit.do).

### 누가 응시할 수 있나요?

**응시 자격 제한은 없습니다.** 전공이나 학년을 필수 자격으로 요구하지 않습니다. 접수는 공식 홈페이지에서 온라인으로 진행하며, 회원가입·사진 등록·원서 제출·응시료 결제 후 접수 완료 여부를 확인합니다. 일반 응시료는 **20,000원**, MOU 체결기관 단체접수는 50% 할인 규정이 있습니다. 단체접수 방법과 응시료 지원 여부는 학교 안내를 확인하세요. [2026 시행계획 공고, 첨부 2~3쪽](https://www.topcit.or.kr/board/notice/detail.do?seq=841)

### 2026년에는 무엇을 평가하나요?

**2026년 제25회 정기평가부터 개편 기준이 적용**됩니다. 현재 시험은 기술 영역 3개와 비즈니스 영역 1개로 구성됩니다. [2026 시험 변경 안내, 첨부 1~2쪽](https://www.topcit.or.kr/board/notice/detail.do?seq=842)

| 구분 | 평가 영역 | 문항 수 | 배점 | 이번 특강과의 관계 |
| --- | --- | ---: | ---: | --- |
| 기술 | 소프트웨어 개발 | 21 | 365점 | 별도 학습이 필요한 영역 |
| 기술 | 데이터 관리 | 19 | 265점 | 별도 학습이 필요한 영역 |
| 기술 | 시스템아키텍처 및 정보보안 | 18 | 235점 | 2·3회차 주제 |
| 비즈니스 | IT비즈니스 | 17 | 135점 | 1회차의 윤리·프로젝트 관리·기술 의사소통 포함 |
| 합계 | 4개 영역 | 75 | 1,000점 | 특강은 시험 전체 범위 중 일부를 다룸 |

영역별 수치 출처: [2026 시험 변경 안내, 첨부 1쪽](https://www.topcit.or.kr/board/notice/detail.do?seq=842), [공식 평가체계의 영역별 표](https://www.topcit.or.kr/introduction/question.do).

기술과 비즈니스가 결합된 통합문제는 기술 영역마다 1문항씩 포함됩니다. 별도의 통합 영역을 추가해 문항 수나 배점을 중복 계산하지 않습니다. [2026 시험 변경 안내, 첨부 1쪽](https://www.topcit.or.kr/board/notice/detail.do?seq=842)

통합 수행형은 기술과 비즈니스가 결합된 문제이므로 비즈니스 지식도 수행형에 활용됩니다. 수행형이 배정되어 있다는 사실만으로 해당 영역에서 실제 코딩이나 UML 작업을 요구한다고 단정할 수는 없습니다. 공개 예제로 문제에서 요구하는 답안 형식을 확인하며 준비하세요. [2026 시험 변경 안내의 통합문제 정의](https://www.topcit.or.kr/board/notice/detail.do?seq=842)

시험은 **고사장에서 컴퓨터로 응시**합니다. 공식 연습 페이지에서 모의응시, 다이어그램 작성 도구와 컴파일러 연습을 안내합니다. 온라인 접수라고 해서 집에서 원격 응시하는 시험을 뜻하지 않습니다. [공식 연습 안내](https://www.topcit.or.kr/board/preview.do), [2026 시행계획 공고](https://www.topcit.or.kr/board/notice/detail.do?seq=841)

### 무엇을 준비하나요?

- 필기도구는 지참할 수 있습니다. 별도 종이는 가져갈 수 없고 수험표 뒷면에 풀이한 뒤 감독관에게 제출합니다. 시험시간의 절반이 지나기 전에는 퇴실할 수 없습니다. [공식 한국어 접수방법](https://www.topcit.or.kr/receipt/help.do?language=ko)
- **인정되는 신분증과 출력한 수험표**를 준비합니다. 주민등록증·국내 운전면허증·유효기간 내 여권 등이 인정됩니다. 대학 학생증을 사용할 계획이라면 공식 신분증 인정 범위를 먼저 확인하세요. [2026 시행계획 공고, 첨부 5쪽](https://www.topcit.or.kr/board/notice/detail.do?seq=841)
- **모바일 신분증은 2026년 제25회부터 인정**되지만, 공지에서 허용한 서비스의 앱을 직접 실행해 확인받아야 합니다. 캡처·저장 이미지나 파일은 인정되지 않으며, 기기 문제로 확인할 수 없으면 미지참으로 처리됩니다. 사용할 서비스의 인정 여부를 미리 확인합니다. [2026-05-14 모바일 신분증 공지](https://www.topcit.or.kr/board/notice/detail.do?seq=844)
- 시간을 볼 시계는 시각 확인만 가능한 단순 손목시계를 사용합니다. 스마트워치는 금지되고, 휴대전화 등 전자기기는 감독관 지시에 따라 보관합니다. 실제 시험시간은 수험자 프로그램으로 관리됩니다. [2026 시행계획 공고, 첨부 6쪽](https://www.topcit.or.kr/board/notice/detail.do?seq=841)
- 시험 전 수험표에서 시험장·고사실·좌석을 확인하고 이동 시간을 확보합니다. 본인 접수 내역에서 수험표 출력 가능 여부를 확인하세요. [접수방법](https://www.topcit.or.kr/receipt/help.do), [2026 시행계획 공고](https://www.topcit.or.kr/board/notice/detail.do?seq=841)

## 4. 강사용 메모 및 문서 발전 방향

### 수업 협의 맥락

수업 요청은 연결된 Gmail에서 확인한 「[목원대학교 SW중심대학사업추진단] TOPCIT 정기평가 대비 특강 강의 문의」 원문과 답장에 근거합니다. 사용자는 2026-09-01에 세 날짜 모두 가능하다고 답장했으며, 학교 측의 후속 확정은 아직 확인하지 않았습니다. 메일에서 요청한 오리엔테이션은 평가 구조와 문항 유형 안내가 중심입니다. 학교 목표 점수나 인정 기준은 메일에 없습니다.

### 학습자료 검토 상태

공식 03~06 교재 PDF를 저장소 밖 임시 경로에 내려받아 목차와 문항 관련 본문을 발췌 검토했습니다. 전권을 처음부터 끝까지 정독한 것은 아닙니다. 판권의 3판 발행일은 2020-02-26이며, 2026 개편판으로 간주하지 않습니다. 문항별 출처는 JSON에 기록하고 구체적인 검토 범위는 [조사 메모](notes/)에 남깁니다. 현재 학습자료 버튼은 PDF가 아니라 HTML 전자책을 엽니다. 활성 전자책 03~06의 실제 판권도 동일한 2020년 3판이며 목차와 대표 본문을 PDF와 대조했습니다. 주석 처리된 PDF 연결 코드를 활성 링크로 읽었던 초기 설명은 조사 메모에 정정했습니다. 전체 파일이 바이트 단위로 동일하거나 더 최신 판본이 어디에도 없다는 뜻은 아닙니다. 모의응시 안내 페이지는 확인했으며 실제 모의시험 실행과 개별 공개 문항 검토는 아직 진행하지 않았습니다. 수행형 배정과 실제 코딩·UML 작업 요구 여부는 구별해 검토해야 합니다.

수험표 발급 시작일은 공식 접수방법의 한국어·영어 표기가 달라 학생 안내에서는 특정 날짜를 단정하지 않고 본인 접수 내역에서 확인하도록 했습니다. [공식 접수방법](https://www.topcit.or.kr/receipt/help.do)

공식 자료는 링크로 참조하며 무료 열람·다운로드를 저장소 재배포 허가로 간주하지 않습니다.

### 문서 발전 방향과 남은 확인 사항

이 프로젝트는 하나의 공개 GitHub 저장소를 강의 교안으로 활용합니다. README에 전체 교안을 담거나 Mermaid를 활용하는 방안을 탐색 중입니다. README에는 개요·오리엔테이션·회차 링크를 두고 상세 교안을 회차별 파일로 나누는 방식, 회차별 개념·예제·해설 구성은 assistant의 제안이며 **아직 확정하지 않았습니다.** 학생용 안내는 문서 앞부분에, 강사용 메모와 문서 발전 방향은 맨 아래에 배치합니다. 전체 교안 작성은 후속 범위입니다.

- 학교 측 일정 확정, 상세 강의실, 단체접수·응시료 지원, 학교의 목표 점수와 활용 기준
- 학생의 전공·선수지식 등 학습자 수준, 교안 형태, 학생 대상 배포·활용 방식, 상세 목차
- 교재 전체의 최신 출제기준 대응, 개별 공식 공개 예제 검토, 실제 공식 모의응시 도구 동작
- 시험 직전 추가 공지와 최종 수험표 정보

### 공식 자료 검토 메모

공식 영문 평가체계 페이지에는 과거 **65문항·단답형 포함** 설명과 새 **75문항** 표가 함께 남아 있습니다. 시행계획 공고 일부 표에도 예전 영역 명칭이 남아 있습니다. 이 README의 영역 명칭·문항 유형·배점은 적용 시점을 명시한 **2026년 변경 안내 첨부 1~2쪽**을 기준으로 정리했고 표를 시각적으로 대조했습니다. 날짜와 응시 규정은 2026 시행계획 공고 및 후속 모바일 신분증 공지를 기준으로 합니다. ### 문제은행 관리

문항 데이터는 `data/`의 순수 JSON이고 문제풀이·전체보기·개념모드는 동일한 데이터를 사용합니다. [문항 편집 안내](AUTHORING.md)에 고유ID, 개정 번호, 추가·삭제와 진도 처리 정책을 정리했습니다. 문제·보기·정답의 의미가 바뀌면 해당 문제만 개정 번호를 올려 진도를 초기화합니다. 단순 오탈자·해설 표현 수정은 개정 번호를 유지할 수 있습니다.

기록 저장은 localStorage, 기기 간 이동은 URL fragment에 담은 압축 진도 스냅샷을 사용합니다. 계정·서버 DB·교사 집계는 없습니다. 링크는 ID·개정 번호·연속 정답만 포함하고 전체 응답 로그는 옮기지 않습니다. 전체 응답 로그는 앱에서 내려받을 수 있습니다. 학습기록은 자기주도 학습용이며 평가 성적 증빙으로 사용하지 않습니다.

로컬 실행은 `npm run serve`, 로직·데이터 검사는 `npm test`, 실제 브라우저 검사는 `npm run test:browser`입니다. 브라우저 검사는 `npm install` 후 `npx playwright install chromium`이 필요합니다. 공개 배포는 GitHub Pages의 `main` 루트를 사용합니다.
