# 핵심 개념 슬라이드 작성·검토

- 구성: 교재 기준 여섯 과목 × 개념 10개 = 60개. 개념 자료 181장과 별도 시험 안내 7장으로 구성했다.
- 선정 기준: 다른 개념을 이해하는 바탕이 되는 원리, 원인과 결과, 혼동하기 쉬운 구분. 출제빈도 순위나 공식 지정 핵심 목록을 의미하지 않는다.
- 내용 원본: `slides/*.md`. `slides/catalog.json`은 과목과 파일의 목록만 보관하며 설명 원문을 중복 저장하지 않는다. HTML은 공통 생성기의 출력이다.
- 예시는 새로 작성했으며 공식 교재의 문장·문제·그림을 복제하지 않았다. 전용 시연은 기존 주공정 자료에만 포함한다. 각 자료에 연습문제는 넣지 않았다.

## 출처와 확인 범위

[공식 학습자료 목록](https://www.topcit.or.kr/board/study.do?language=ko)의 활성 전자책 주소를 확인하고 여섯 전자책의 응답 성공을 확인했다. 전자책별 링크는 각 자료에서 제공한다.

시스템아키텍처·정보보안·IT비즈니스·프로젝트 관리는 기존의 교재 발췌 검토 및 문제은행 조사 메모를 참고했다. 상세 범위는 이 폴더의 과목별 조사 메모에 있다. 소프트웨어와 데이터 자료는 기초 개념을 독립적으로 정리했으며, 이번 작업에서 교재 01·02 본문을 전권 대조한 것은 아니다. 전자책 링크를 출제 보장이나 문장별 대응 증거로 해석하지 않는다.

데이터의 조인과 트랜잭션 설명은 [PostgreSQL 공식 조인 설명](https://www.postgresql.org/docs/current/tutorial-join.html), [공식 트랜잭션 설명](https://www.postgresql.org/docs/current/tutorial-transactions.html)도 참고했다. 일반 개념과 특정 DBMS의 구현을 동일시하지 않았다.

## 병렬 검토

기술 네 과목과 비즈니스 두 과목으로 나누어 원고의 중대한 개념 오류를 검토했다. SQL 사례에서 수강 기록 수를 학생 인원으로 혼동할 수 있는 설명을 발견하여 ‘학과별 수강 건수’로 수정했다. 주공정의 기간·여유, 획득가치 편차, SWOT 구분 등을 검토했다. 이는 전문가 인증이나 전체 교재·시험 범위의 완전한 검증을 뜻하지 않는다.

시험 안내는 기존 README에서 공식 출처와 함께 정리한 정보를 사용한다. 법률·표준의 최신 세부 의무나 특정 제품 버전의 성능을 새로 단정하지 않았다.
