# 시스템아키텍처 문제 작성 근거

이 파일은 문항 작성·검토 메모이며 학생용 교재 본문이 아닙니다.

## 공식 자료

- [공식 학습자료 목록](https://www.topcit.or.kr/board/study.do?language=ko)의 `openEssence('03')`가 지정하는 [03 시스템아키텍처 이해와 활용 PDF](https://www.topcit.or.kr/upload/edubox/essence/pdf/ko/03_%EC%8B%9C%EC%8A%A4%ED%85%9C_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98%EC%9D%B4%ED%95%B4%EC%99%80%20%ED%99%9C%EC%9A%A9.pdf)를 직접 내려받아 확인했습니다.
- PDF는 221쪽입니다. PDF 4쪽 판권 이미지를 확인했으며 **3판 발행일은 2020-02-26**입니다. 페이지 상단의 2022-12-02 시각은 출력 표시이며 교재 발행일로 해석하지 않습니다.
- [2026 변경 공지](https://www.topcit.or.kr/board/notice/detail.do?seq=842)의 [첨부 PDF](https://www.topcit.or.kr/board/pdfPreview.do?seq=120) 1~3쪽을 확인했습니다. 2026년부터 시스템아키텍처와 정보보안은 하나의 평가영역이며, 그 안에서 시스템아키텍처 기본 지식·활용, 운영체제, 네트워크를 평가합니다. 여기의 100문항은 특강 학습 주제별 자체 연습문항 수이며 실제 시험 문항 수가 아닙니다.

## 읽기 방법과 범위

공식 PDF는 저장소 밖 Windows TEMP의 `topcit-architecture.pdf`에만 저장했습니다. Python PyMuPDF의 `page.get_text()`로 목차와 관련 본문을 발췌해 읽었고 판권 PDF 4쪽, 네트워크 목차 PDF 17쪽은 페이지 이미지로 대조했습니다. **221쪽 전체를 처음부터 끝까지 정독한 것은 아닙니다.** 텍스트에는 OCR로 보이는 글자 깨짐이 있어 깨진 문구를 그대로 인용하지 않았습니다.

문항에 사용한 범위는 시스템 구성·계층, 운영체제의 프로세스·스레드·동기화·스케줄링·메모리·파일, CPU·기억장치·병렬 처리, 저장장치·RAID·백업, 용량 산정, 고가용성과 재해 복구, 클라우드 서비스·가상화, 분산 저장, 데이터링크·IP·전송·응용 계층, SDN입니다. 각 문항의 `source.section`에 관련 교재 절과 확인 가능한 인쇄 쪽 범위를 기록했습니다. 인쇄 쪽은 PDF 페이지 번호와 다릅니다(예: 인쇄 49쪽은 PDF 51쪽).

2020년 교재와 2026 출제기준이 완전히 일치한다고 보지 않습니다. 최신 제품 버전·시장 동향의 수치와 시대에 따라 달라지는 구현 제약은 문제화하지 않았습니다. 교재 내용 전체의 최신성이나 오류 없음까지 검증한 것은 아닙니다.

## 문항과 품질 확인

- `data/architecture.json`: 정확히 100문항, ID `arch-001`~`arch-100`, 학습영역 `architecture`, 첫 공개 revision 1.
- 네 보기 중 하나를 고르는 독창적 한국어 연습문항입니다. 공식 기출이나 교재 문제를 복사하지 않았으며 정답 이유와 유사 개념의 차이를 작성했습니다.
- 정답 위치는 네 위치에 각각 25개로 분배했습니다. 앱은 별도로 보기를 섞을 수 있습니다.
- 수치 문항은 HRN (8+2)/2=5, RAID 5 (4−1)×2TB=6TB, /26 호스트 주소 2^6−2=62개, 192.168.10.70/26의 네트워크 .64를 다시 계산했습니다.
- ID·질문 중복, 보기 개수/중복, 정답 인덱스, revision과 출처 필드의 형식을 검사했습니다.
- 동료 검토에서 발견된 보기 변경 전 해설 잔재를 수정하고 정답 텍스트와 해설을 100개 모두 다시 대조했습니다.
- 개별 문항의 의미를 변경할 때는 기존 ID를 유지하면서 revision을 올려 이전 학습 기록과 구별합니다.
- 기초 개념 식별과 간단한 적용 연습이 중심이며 실제 TOPCIT 난도·출제 빈도를 보장하지 않습니다.

공식 원문은 링크로만 참조합니다. 무료 제공은 재배포 허가로 해석하지 않습니다.
