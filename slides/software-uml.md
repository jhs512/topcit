# UML과 모델의 관점

과목명: 소프트웨어 개발 · 핵심 개념 07

UML은 소프트웨어의 구조와 동작을 표현하는 모델링 언어입니다. **설명하려는 질문에 맞는 다이어그램**을 선택합니다.

## 시스템을 여러 관점으로 표현하는 이유

하나의 그림에 모든 정보를 담으면 중요한 관계나 흐름이 가려집니다.

---

# 주문 처리 설명

객체 간 호출 순서는 시퀀스 다이어그램, 주문의 상태 변화는 상태 다이어그램, 타입 간 관계는 클래스 다이어그램으로 설명할 수 있습니다.

## 사례에서 확인할 원리

모델은 목적에 맞게 생략한 표현입니다. UML을 그렸다는 사실만으로 요구 충족이나 설계의 정확성이 보장되지는 않습니다.
