# 부하분산과 고가용성

과목명: 시스템아키텍처 · 핵심 개념 09

부하분산은 요청을 여러 처리 자원에 나눕니다. 고가용성은 **장애 상황에서도 서비스를 지속**하도록 설계하는 목표입니다.

## 여러 서버만으로 고가용성이 보장되는가

서버 수만 늘려도 공통 의존점이 고장 나면 서비스 전체가 중단될 수 있습니다.

---

# 웹 서버 두 대

웹 서버를 두 대 두어도 공통 데이터베이스 한 대가 멈추면 요청 처리가 실패할 수 있습니다. 전체 의존 경로의 단일 장애점을 살펴봅니다.

## 사례에서 확인할 원리

장애 감지·전환·상태 관리가 함께 필요합니다. 복제 시스템에서는 데이터 일관성과 전환 중 손실 가능성도 검토합니다.
