주공정과 프로젝트 완료 기간

TOPCIT · 프로젝트 관리

주공정은 프로젝트 시작부터 끝까지 이어지는 경로 중, 소요 기간이 가장 긴 경로입니다.

작업 기간 선행 작업
A 요구사항 2일 없음
B 서버 개발 5일 A
C 화면 개발 3일 A
D 통합 테스트 2일 B와 C 모두

B와 C는 병렬로 진행합니다. D는 둘 다 끝나야 시작하므로 전체 완료까지 9일이 걸립니다.

선행 작업이 끝나면 즉시 시작하며, 인력·자원 제약과 대기시간은 없다고 가정합니다.

가장 긴 경로가 완료 기간을 결정합니다

A → B → D: 2 + 5 + 2 = 9일

A → C → D: 2 + 3 + 2 = 7일

주공정은 A → B → D입니다. 이 경로의 작업이 늦어지면, 다른 조건이 같을 때 프로젝트 완료도 늦어집니다.

C는 2일의 여유가 있습니다. C가 3일에서 5일로 늘어나도 D의 시작 시점은 같습니다.

모든 작업 기간을 더한 12일은 완료 기간과 다릅니다. B와 C는 동시에 진행하므로 두 기간을 모두 더하지 않습니다.

화면 개발 기간에 따른 완료일 변화

A는 2일, B는 5일, D는 2일로 고정합니다.

슬라이더 또는 좌우 방향키로 기간을 바꿔 보세요.

2 + max(5, 3) + 2
= 9일

주공정은 A → B → D입니다.

C가 2일 더 걸려도 전체 완료 기간은 같습니다.

공식 교재 06 — 주공정법(CPM), 인쇄 93쪽

예시의 작업·기간은 수업용으로 새로 구성했습니다. 공식 기출문제나 출제 예측 자료가 아닙니다.
