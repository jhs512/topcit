# 알고리즘과 시간복잡도

과목명: 소프트웨어 개발 · 핵심 개념 04

시간복잡도는 입력 크기가 증가할 때 **연산량이 어떻게 증가하는지** 나타냅니다. 실제 초 단위 시간과는 구분합니다.

## 입력 크기에 따른 계산량을 비교하는 이유

작은 입력에서 빠른 코드도 입력이 커지면 증가율 때문에 감당하기 어려워질 수 있습니다.

# 순차 탐색과 이진 탐색

순차 탐색은 최악에 모든 항목을 확인합니다. 정렬된 배열의 이진 탐색은 매 단계 후보 범위를 절반으로 줄입니다.

## 사례에서 확인할 원리

이진 탐색의 조건인 정렬과 접근 구조를 확인해야 합니다. 준비 비용과 메모리 사용량도 함께 고려합니다.
