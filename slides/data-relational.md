# 관계형 데이터 모델

데이터 이해와 활용 · 핵심 개념 01

관계형 모델은 데이터를 관계로 표현하고 속성과 값의 규칙을 정의합니다. SQL 데이터베이스에서는 **테이블·행·열**로 다룹니다.

## 왜 필요한가

구조와 제약을 정하면 같은 의미의 데이터를 일관되게 저장하고 조회할 수 있습니다.

---

# 학생과 수강 기록

학생 정보와 수강 정보를 나누고 학생 식별자로 연결하면, 이름을 여러 수강 행에 반복해서 적지 않아도 됩니다.

## 사례에서 확인할 원리

행의 저장 순서는 조회 결과의 순서를 보장하지 않습니다. SQL 결과 순서가 필요하면 정렬 기준을 지정합니다.
