# 자료구조와 접근 방식

과목명: 소프트웨어 개발 · 핵심 개념 03

자료구조는 데이터를 저장하고 접근하는 조직 방식입니다. **어떤 연산을 자주 하는지**에 맞춰 선택합니다.

## 접근 방식에 맞는 자료구조를 고르는 이유

같은 데이터라도 검색·삽입·삭제·순회 비용이 구조에 따라 달라집니다.

---

# 작업 대기열

먼저 들어온 작업을 먼저 처리하려면 큐가 적합합니다. 최근 작업을 먼저 되돌리는 실행 취소에는 스택 방식이 어울립니다.

## 사례에서 확인할 원리

구조의 이름보다 연산과 순서를 먼저 봅니다. 해싱은 키에 함수를 적용해 저장 위치를 계산하는 탐색 방식입니다.
