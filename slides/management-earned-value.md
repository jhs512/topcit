# 진척과 획득가치

프로젝트 관리와 소통 · 핵심 개념 06

획득가치는 완료한 작업을 **계획 예산 기준으로 환산한 값**입니다. 지출액만으로는 진척을 알 수 없습니다.

## 왜 필요한가

많이 썼다는 사실과 많이 완성했다는 사실을 구분해야 합니다.

---

# 예산 기준으로 진척 비교

계획가치 PV=100, 획득가치 EV=80, 실제원가 AC=90이라면 일정편차는 −20, 원가편차는 −10입니다.

## 사례에서 확인할 원리

일정편차 EV−PV는 예산 단위의 지표입니다. −20을 곧바로 20일 지연으로 해석하지 않습니다.

# 진척과 획득가치의 핵심 구분

| 개념 | 의미 |
| --- | --- |

| EV | 완료한 작업의 예산 |
| AC | 실제로 쓴 비용 |
