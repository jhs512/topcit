# SQL 조회와 집계

데이터 이해와 활용 · 핵심 개념 05

조회는 조건에 맞는 데이터를 선택하고 필요한 결과를 구성합니다. 집계는 **여러 행을 요약한 값**을 만듭니다.

## 왜 필요한가

개별 행에 대한 조건과 그룹 전체에 대한 조건을 구분해야 원하는 결과를 얻습니다.

---

# 학과별 수강 건수

개별 수강 기록을 조건으로 거른 뒤 학과별로 묶어 수강 건수를 셉니다. 일정 건수 이상인 학과만 남기려면 집계 결과에 조건을 적용합니다.

## 사례에서 확인할 원리

WHERE는 집계 전 행 조건, HAVING은 그룹 조건에 사용합니다. NULL은 값이 없음을 표현하므로 일반 값과 비교하는 방식에 주의합니다.

---

# SQL 조회와 집계의 핵심 구분

| 개념 | 의미 |
| --- | --- |
| WHERE | 행 필터 |
| GROUP BY | 그룹 구성 |
| 집계 함수 | COUNT·SUM 등 |
| HAVING | 그룹 필터 |
