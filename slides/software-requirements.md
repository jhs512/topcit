# 요구사항 분석

소프트웨어 개발 · 핵심 개념 01

요구사항은 시스템이 제공할 기능과 지켜야 할 조건입니다. **이해관계자의 필요를 확인 가능한 기준**으로 바꿉니다.

## 왜 필요한가

모호한 요구는 구현 후에도 완료 여부를 합의하기 어렵게 만듭니다.

---

# 빠른 검색이라는 요구

검색 기능 제공은 기능 요구입니다. 정해진 데이터와 부하에서 응답시간을 만족해야 한다는 조건은 성능 요구입니다.

## 사례에서 확인할 원리

기능 요구와 비기능 요구를 함께 관리합니다. 사용자 요구와 설계 결정을 구분하고 변경의 영향을 추적합니다.
