# 강의 슬라이드 작성

마크다운이 내용의 원본이며, HTML은 생성 결과입니다. HTML을 직접 편집하지 않습니다.

각 개념은 하나의 마크다운 파일로 작성합니다. `# 제목`으로 각 슬라이드를 시작하고, 단독 줄의 `---`로 슬라이드를 나눕니다. 기본 구성은 개념 설명 → 구체적인 예시 → 비교 또는 변화 설명입니다. 연습문제를 필수 단계로 넣지 않습니다. 개념에 맞지 않는 시연은 생략합니다.

설명·표·강조·출처 링크는 마크다운에 작성합니다. 공통 글꼴·색·여백은 `theme/slides.css`, 넘기기·전체 화면은 `theme/slides.js`에서 관리합니다. 현재 `critical-path` 시연은 전용 HTML과 동작 코드로 구현한 선택 구성요소입니다. 시연의 고정 작업 기간을 바꿀 때에는 해당 구성요소도 함께 수정해야 합니다.

```sh
npm run build:slides
```

명령은 이 폴더의 README를 제외한 마크다운을 HTML로 생성합니다. 작성자가 관리하는 로컬 원본 전용이며, 외부 사용자가 올린 마크다운을 실행하는 서비스가 아닙니다.

현재 출력 형식은 HTML입니다. PowerPoint 파일 변환은 아직 구현하지 않았으며, 향후에도 내용 원본은 이 마크다운을 사용합니다. HTML 시연은 PowerPoint에서 같은 방식으로 실행되지 않습니다.

견본: [원본](critical-path.md) · [발표 화면](critical-path.html)

## 과목별 자료 관리

`catalog.json`에는 여섯 과목의 이름과 각 10개 자료의 파일 경로만 기록합니다. 설명 내용은 각 마크다운 파일 한 곳에서 수정합니다. 자료 제목이나 파일 이름을 바꾸면 목록과 최상위 README의 링크도 함께 갱신합니다.

현재 개념 자료는 60개이며 시험 안내는 별도입니다. 공통 수업 흐름은 개념과 필요성 → 구체적 사례 → 핵심 구분입니다. 기존 견본의 시연과 4장 구성은 유지합니다. 전체 본문을 일괄 재작성하는 별도 데이터 파일은 원본으로 사용하지 않습니다.

슬라이드별로 설명량이 많은 경우 제목 아래에 `<!-- layout: compact -->`를 넣어 공통 압축 배치를 선택할 수 있습니다. 본문 내용은 그대로 원본에 유지합니다. 검사는 `npm run test:slides`로 실행합니다.
