# 가상메모리와 페이지

시스템아키텍처 · 핵심 개념 05

가상메모리는 프로세스가 사용하는 주소와 실제 물리메모리 주소를 분리합니다. **페이지 단위 주소 변환과 보호**를 지원합니다.

## 왜 필요한가

프로세스별 주소 공간을 제공하고 필요한 데이터를 물리메모리에 배치할 수 있습니다.

---

# 페이지 부재 처리

프로세스가 접근한 페이지가 물리메모리에 없으면 페이지 폴트가 발생합니다. 운영체제가 필요한 처리를 한 뒤 실행을 재개합니다.

## 사례에서 확인할 원리

페이지 폴트가 항상 디스크 읽기를 뜻하지는 않습니다. 잦은 페이지 교체 때문에 작업보다 이동에 시간을 쓰는 현상은 스래싱입니다.
