# 가상메모리와 페이지

과목명: 시스템아키텍처 · 핵심 개념 05

가상메모리는 프로세스가 사용하는 주소와 실제 물리메모리 주소를 분리합니다. 페이징 방식에서는 **같은 크기의 페이지를 물리메모리의 프레임에 배치**합니다.

## 가상주소와 물리주소를 왜 나누는가

프로세스별 주소 공간을 제공하고 필요한 데이터를 물리메모리에 배치할 수 있습니다.

---

# 페이지를 새로 적재할 공간이 없다면

물리메모리의 프레임이 모두 사용 중이라면, 새 페이지를 넣기 전에 교체할 페이지를 골라야 합니다. FIFO는 먼저 들어온 페이지를, LRU는 가장 오래 사용하지 않은 페이지를 고릅니다.

## 사례에서 확인할 원리

페이지 크기와 교체 정책은 다른 문제입니다. 페이지는 나누는 단위이고, 교체 정책은 공간이 부족할 때 무엇을 내보낼지 정하는 규칙입니다.
