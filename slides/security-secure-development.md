# 안전한 소프트웨어 개발

과목명: 정보보안 · 핵심 개념 08

안전한 개발은 설계부터 운영까지 **입력·권한·데이터 처리의 신뢰 경계**를 다루는 활동입니다.

## 개발 단계부터 보안을 왜 고려하는가

외부 입력을 신뢰하거나 보안을 출시 직전 검사에만 맡기면 구조적인 약점이 남을 수 있습니다.

---

# 검색 입력과 화면 출력

데이터베이스 질의에는 매개변수화된 질의를 사용하고, 화면 출력은 출력 맥락에 맞게 인코딩합니다. 목적이 다른 방어를 구분합니다.

## 사례에서 확인할 원리

입력 검증만으로 모든 취약점을 막을 수 없습니다. 서버 측 권한 검사, 안전한 비밀 관리, 의존성 점검도 함께 필요합니다.
