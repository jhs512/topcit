# 인덱스와 조회 비용

과목명: 데이터 이해와 활용 · 핵심 개념 09

인덱스는 조건에 맞는 데이터 위치를 찾는 보조 구조입니다. **데이터에 접근하는 경로**를 만들어 탐색 범위를 줄입니다.

## 인덱스로 접근 경로를 만드는 이유

인덱스는 조회 조건과 데이터 분포에 맞게 설계해야 합니다. 여러 접근 경로 중 실제 비용이 낮은 경로를 판단해야 합니다.

---

# 주문 번호 검색

수백만 주문 중 특정 주문 번호를 찾을 때 인덱스가 도움이 될 수 있습니다. 대부분의 행을 읽는 조회에서는 전체 탐색이 더 유리할 수도 있습니다.

## 사례에서 확인할 원리

인덱스가 있어도 항상 사용하지는 않습니다. 조건·데이터 분포·통계와 실행계획을 보고 실제 비용을 확인합니다.
