# 키와 무결성

과목명: 데이터 이해와 활용 · 핵심 개념 02

키는 행을 식별하거나 테이블 사이 관계를 연결합니다. 무결성 제약은 **데이터가 지켜야 할 규칙**을 강제합니다.

## 데이터 식별과 무결성이 필요한 이유

응용 프로그램에서만 검사하면 다른 입력 경로에서 잘못된 데이터가 들어올 수 있습니다.

---

# 학생과 수강의 연결

학생의 기본키는 학생을 유일하게 식별합니다. 수강의 학생 식별자가 외래키라면 존재하는 학생과 연결되도록 제약할 수 있습니다.

## 사례에서 확인할 원리

외래키 값은 중복될 수 있고, 별도 NOT NULL 제약이 없다면 NULL도 허용될 수 있습니다. 한 학생이 여러 과목을 수강하면 학생 식별자가 여러 번 나옵니다.
